# Logs

Mini writes `MINI-ARMED.md` before the desk hash. One line: `MINI_ARMED` and the UTC time Mini armed. That line is how the desk sees Mini. A sentence in another chat is not the signal. The file is absent until Mini pushes it.

After the run, the method log lands here. It records the clock, each phase, the On origin time of each hash file, and whether `counts/desk/` and `counts/mini/` were pushed by the runners. The day is Sun 8 Nov 2026. Start is 12:00 UTC. The 10:40 UTC waiter was stopped before the hash.

The 8 Nov record stays in [that rehearsal](https://github.com/STP-KAS/tn10-storm-2026-11-08/blob/main/logs/METHOD.md). This folder does not copy it.

No key, seed, txid, covenant id, address, host, or port.
